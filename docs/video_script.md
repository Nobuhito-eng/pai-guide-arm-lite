# 動画台本（実測後に使用）

目標は約110～150秒。動画は1～3分。実時間を測って超えたときだけ編集/2倍速化し、倍速を明記する。

## 冒頭（10～15秒）
「AI案内アーム・ライトです。入力文を小型の学習済み分類器で受付・出口・保留に分類します。受付はA方向、出口はB方向を示します。曖昧な入力では新しい動作を開始しません。」

## 実演（03_DEMO）
Gazeboと、入力・AI判定の端末を一画面に並べる。顔出し・BGMは不要。
1. 受付はどちらですか → 受付Aへ → 待機に戻る
2. 出口へ案内してください → 出口Bへ → 待機に戻る
3. あちらをお願いします → 保留（目標送信0）
これを2回。成功・失敗はログのまま説明する。

## 終わり（10～15秒）
「案内先の判断はAI、姿勢の実行は既存のROS制御です。［実際の確認結果］。今回の3入力は学習例にも含むため、広い日本語理解の精度は検証していません。保留は非常停止ではなく、シミュレータ上での新規指令を抑えるものです。」

## 最後の点検
- 個人名/所属/メール/通知/トークンが映っていない
- ロボットの動き、2案内先の違い、保留が分かる
- 再生時間1～3分、倍速使用時は明記
- YouTubeタイトルは要項のOmnicampus名形式、限定公開以上
