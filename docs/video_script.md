# 実演の構成

`03_DEMO.cmd`は次の3場面を順に2回実行します。

| 入力 | 分類 | 動作 |
|---|---|---|
|受付はどちらですか|受付|受付側の姿勢へ移動し、待機姿勢へ戻る|
|出口へ案内してください|出口|出口側の姿勢へ移動し、待機姿勢へ戻る|
|あちらをお願いします|保留|新しい動作指令を送らず、関節状態を観測する|

案内先は小型分類器で選択し、姿勢の実行にはROS 2の関節軌道制御を使用します。デモの3入力は学習例文にも含まれるため、この実演は独立した精度評価ではありません。保留は新規指令を抑える処理であり、非常停止ではありません。

2026-10-15の録画は実Gazeboを等倍・無音で収録した109.667秒の動画です。6試行と案内・復帰の計8指令が成功し、入力と判定を字幕で表示しています。
